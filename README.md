# Nyeri County Business Size Classification Using Machine Learning

## Project Overview

This project develops a machine learning pipeline for classifying business size categories using business permit data from the County Government of Nyeri.

The project applies supervised machine learning techniques to explore business characteristics and predict business size categories using:

- Decision Tree
- Random Forest

The project also focuses on preventing data leakage during preprocessing and model development.

## Objectives

The main objectives of this project are to:

1. Explore and understand business permit data.
2. Clean and preprocess the dataset.
3. Prepare features for machine learning.
4. Classify businesses into different size categories.
5. Train Decision Tree and Random Forest classification models.
6. Evaluate and compare model performance.
7. Identify useful patterns in the business data.

## Dataset

The dataset consists of business permit records containing information related to businesses registered within Nyeri County.

Example variables include:

- Business ID
- Permit Number
- Business Activity
- Activity Description
- Business Description
- Business Size Category

Sensitive or confidential information should not be shared publicly.
